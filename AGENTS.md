# AI Best Practices — Semgrep Rules (Deprecated)

All rules have been migrated to the official Semgrep registry at https://github.com/semgrep/semgrep-rules/tree/develop/ai/ai-best-practices and are accessible via the rule pack at https://semgrep.dev/p/ai-best-practices.

This repo now serves only as a redirect/deprecation notice.
